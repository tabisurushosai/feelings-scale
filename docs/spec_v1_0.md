# feelings-scale (きもちものさし) 仕様書 v1_0
## ゴール
今の気持ちを5段階から選ぶと、その段階の「こうするといい」対処カードが出るChrome拡張。子供の感情の自己調整(セルフレギュレーション)を支援。
## 絶対制約
外部API・通信なし/chrome.storage.localのみ/権限storageのみ/MV3・TS・Vite/UIはpopup内で完結。医療・診断をうたわない。
## 機能
5段階の気持ちものさし(例: おちつき/すこしモヤモヤ/イライラ/かなりイライラ/ばくはつしそう を色と顔で)/段階を選ぶと、その段階の対処カード(深呼吸する/みずをのむ/すきな場所へ 等)を表示/対処カードは保護者が編集(段階ごと)/プリセット内蔵/選んだ記録は任意で保持(クリア可)/保護者・子供モードを簡易PINで保護/全状態を保存・復元/i18n ja-en/無料は基本、Premium($3買い切り7日トライアル)で対処カード自由編集+ふりかえり履歴。
